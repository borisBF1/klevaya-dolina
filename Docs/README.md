# Документы проекта

Рабочие документы, по которым ИИ-агенты (Claude Code) делали игру. Большинство из них — спецификации обновлений:
решения автора («Решения владельца» Р1–Р84), план, контракт заголовков и правила для исполнителей. Тексты писали
агенты по заданиям и ответам автора. Часть документов на английском: это контракты для агентов.

| Файл | Что внутри |
|---|---|
| [DETAILS.md](DETAILS.md) | подробное описание проекта: механики, техника, структура, сборка, тесты, ограничения, роль автора, галерея |
| [DESIGN.md](DESIGN.md) | исходная дизайн- и инженерная спецификация: механики, баланс, стиль, правила для агентов |
| [UPDATE_HOME.md](UPDATE_HOME.md) | обновление 2 «Дом, ремёсла и торговля»: правила для исполнителей (§0), владение файлами |
| [UPDATE3_UI.md](UPDATE3_UI.md) | обновление 3: интерфейс (прокрутка, свайпы, учебник), с дословными просьбами автора |
| [UPDATE4_ONLINE.md](UPDATE4_ONLINE.md) | обновление 4: онлайн — протокол API, сезоны, админка, поведение клиента, проверка версии |
| [UPDATE5_LEGENDS.md](UPDATE5_LEGENDS.md) | обновление 5 «Легенды долины»: бои легенд, баланс, решения автора после его игры |
| [UPDATE6_FOREST_CITY.md](UPDATE6_FOREST_CITY.md) | обновление 6 «Лес, двор и Город»: решения Р1–Р70, план и контракт (§17), идеи автора дословно (Приложение А) |
| [UPDATE6_ART.md](UPDATE6_ART.md) | арт-библия обновления 6 |
| [UPDATE6_PACKAGES.json](UPDATE6_PACKAGES.json) | 37 пакетов работ для агентов (волны, файлы, ссылки на спецификацию) |
| [EXPERT_REWORK.md](EXPERT_REWORK.md) | предложение агента по переделке экспертной рыбалки «на согласование владельцу» |
| [UPDATE6_RELEASE_NOTES.md](UPDATE6_RELEASE_NOTES.md) | итог обновления 6: что вошло, как проверить, известные недочёты, раунды правок |
| [HOTFIX_062_RODS.md](HOTFIX_062_RODS.md) | хот-фикс 0.6.2: баг, решения Р79–Р84, план, ход работы, итог автотеста и APK |
| [SERVER.md](SERVER.md) | установка сервера на хостинг, админка, турниры, защита, локальная проверка |
| [CodeMap/](CodeMap/) | карты кода по областям — агенты читают их вместо больших файлов |
| [screenshots/](screenshots/) | картинки для README (сняты в игре) |
