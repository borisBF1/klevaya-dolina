# Сервер «Клёвой долины» — установка на виртуальный хостинг (PHP + MySQL)

> Публичная версия инструкции: адрес сервера заменён на `https://example.com/Fishing-game/`, данные хостинга
> автора убраны. Подставьте свой домен.

Сервер хранит профили игроков (имя, номер #1042, секретный ключ), рейтинги, турниры, почту и резервные копии
сохранений. Это PHP + MySQL, всё лежит в **одной папке** `Fishing-game` на сайте. Остальные файлы сайта
не трогаются.

* Страница скачивания игры (для игроков): **https://example.com/Fishing-game/**
* Файл игры (APK): **https://example.com/Fishing-game/download/KlevayaDolina.apk**
* Адрес API для игры: **https://example.com/Fishing-game/api.php**
* Админка: **https://example.com/Fishing-game/admin/**
* В репозитории: `Server/Fishing-game/` (то, что заливается на хостинг), `Server/tests/` (тесты),
  `Server/local/` (только для проверки на компьютере, **не заливать**).

Нужно: PHP 8.0 или новее и MySQL. В панели хостинга у сайта должна быть выбрана версия PHP 8.x
(«Сайты» → сайт → «Изменить» → версия PHP).

## Шаг 1. База данных MySQL

1. Панель управления хостингом (например, ISPmanager) → **«Базы данных»** → **«Создать базу данных»**.
2. Имя базы, например `fishing` (панель добавит префикс: получится что-то вроде `u1234567_fishing`).
3. Пользователь: «создать нового», имя например `fishing`, пароль — **придумайте сами** (длинный).
   Кодировка — `utf8mb4`, если панель спрашивает.
4. Запишите: полное имя базы, полное имя пользователя, пароль. Сервер базы — `localhost`.

## Шаг 2. Загрузка файлов

1. Откройте «Менеджер файлов» панели (или FTP-клиент, например FileZilla) и зайдите в папку сайта
   `www/<ваш-домен>/`. Создайте в ней папку **`Fishing-game`** (регистр букв важен).
2. Загрузите **содержимое** папки `Server/Fishing-game/` из проекта **внутрь** `Fishing-game/` на хостинге:
   `api.php`, `install.php`, `config.sample.php`, `index.php`, `.htaccess`, папки `lib/`, `admin/`, `download/`, `logs/`.
   Из `logs/` нужен только `.htaccess` (файл `error_log.php`, если он есть у вас на компьютере, не загружайте).
3. Проверьте, что загрузились скрытые файлы `.htaccess` (в корне папки, в `lib/`, `logs/` и `download/`).
   В FileZilla: «Сервер» → «Принудительно показывать скрытые файлы».
4. Если на хостинге остался старый `index.html` (сервер версии 1.0), удалите его — теперь главная страница `index.php`.
5. Больше ничего на сайте не меняйте.

## Шаг 3. Файл настроек config.php

1. В папке `Fishing-game/` на хостинге скопируйте `config.sample.php` в **`config.php`**
   (в менеджере файлов: «Копировать», новое имя `config.php`).
2. Откройте `config.php` на редактирование и **впишите сами**:
   * `db_dsn` — замените `ИМЯ_БАЗЫ` на полное имя базы: `mysql:host=localhost;dbname=u1234567_fishing;charset=utf8mb4`
   * `db_user` — полное имя пользователя базы;
   * `db_pass` — пароль пользователя базы;
   * `admin_password` — пароль для входа в админку (не короче 8 символов; никому не сообщайте);
   * `install_key` — любая строка из 8+ символов, которую знаете только вы (нужна один раз для установки).
3. Сохраните. Файл `config.php` закрыт от просмотра через браузер (`.htaccess`), его не нужно никуда отправлять.

## Шаг 4. Создание таблиц

1. Откройте в браузере: `https://example.com/Fishing-game/install.php?key=ВАШ_install_key`
2. Должно появиться зелёное «Готово: база данных создана».
   Если красная ошибка — проверьте имя базы, пользователя и пароль в `config.php`.
3. **Удалите файл `install.php`** с хостинга.

## Шаг 5. Проверка

* `https://example.com/Fishing-game/api.php?a=ping` → ответ вида `{"ok":true,"server_time":...,"version":{"latest_build":4,...}}`.
* `https://example.com/Fishing-game/` → страница «Клёвая долина» с кнопкой «Скачать для Android».
* `https://example.com/Fishing-game/config.php` и `.../lib/db.php` → «Forbidden» (так и должно быть).
* `https://example.com/Fishing-game/admin/` → страница входа; войдите паролем `admin_password`.

Адрес сервера задаётся в игре: константа `FV_SERVER_BASE_URL` в `Source/FishingValley/Private/FVOnline.cpp` или
`ServerUrl` в `Config/DefaultGame.ini` (секция `[FishingValley.Online]`, в кавычках).
Для проверки на другом сервере игру можно запустить с параметром `-fvserver=<адрес api.php>`.

## Шаг 6. Выложить игру (APK) и указать версию

Игра распространяется только как файл для Android (APK) со страницы https://example.com/Fishing-game/.

1. Соберите APK. Номер сборки в игре (`UFVOnline::ClientBuild()`, сейчас **4**) и в Android (`StoreVersion` в
   `Config/DefaultEngine.ini`) должны совпадать, название версии — `VersionDisplayName` (сейчас **0.4**).
2. Панель хостинга → «Менеджер файлов» → `www/<ваш-домен>/Fishing-game/download/` → «Загрузить» →
   файл с именем **`KlevayaDolina.apk`** (при обновлении — заменить старый). Если менеджер файлов не справляется с большим
   файлом, загрузите его через FileZilla. Папку `download/` и её `.htaccess` (он отдаёт APK с правильным типом для Android) не удаляйте.
3. Админка → **«Версия игры»**: название версии (например `0.4`), номер сборки (`4`), минимальная сборка (`4`),
   ссылка на APK (по умолчанию уже верная) и «Что нового» (каждая строка — отдельный пункт) → «Сохранить».
   На этой же странице видно, найден ли файл APK на сервере и его размер.
4. Откройте https://example.com/Fishing-game/ с телефона: версия, «Что нового», размер файла и кнопка
   «Скачать для Android» должны быть на месте. Пока файла нет, кнопка серая («Файл новой версии загружается»).

**Как игра использует версию.** При запуске игра спрашивает сервер (`ping`) и сравнивает свою сборку:
ниже **минимальной** — играть нельзя, игрок видит «Скачать новую версию»; ниже **последней** — предложение
«Обновить» / «Позже». Выпуск обновления: собрать APK со сборкой на 1 больше → заменить файл в `download/` →
в «Версии игры» поднять номер сборки и название, написать «Что нового». Минимальную сборку поднимайте, только
если старые версии больше не должны работать. Если сервер недоступен, игра предлагает «Играть офлайн».

## Админка: что где

* **Обзор** — сколько игроков, кто активен, текущий турнир (время до конца, лидеры), подозрительные игроки.
* **Игроки** — поиск по имени, `#1042` (номер под именем) или номеру игрока, сортировка по столбцам.
* **Страница игрока** — профиль и статистика; блокировка / разблокировка с причиной (игрок её увидит);
  подарок (монеты, опыт, «поднять до уровня», предмет) и сообщение — приходят игроку письмом;
  сброс имени; заметки; сохранения: «скачать .sav» и «создать код восстановления»; история писем.
* **Восстановление сохранения:** страница игрока → «Сохранения» → «создать код восстановления» у нужной копии →
  код из 8 символов сообщите игроку. Он вводит его в игре: «Настройки» → «Восстановить сохранение».
  Код одноразовый и действует 7 дней. После восстановления сервер спокойно принимает «откат» счётчиков игрока.
* **Турниры** — таблица наград для любого уровня, история, участники с местами и наградами по категориям;
  **Рассылка** — письмо всем игрокам; **Версия игры** — последняя и минимальная сборка, ссылка на APK, «Что нового»;
  **Журнал** — все действия админки (и входы).

## Турниры

Турниры идут друг за другом **каждые 3 реальных дня** (72 часа по часам сервера, игровое время ни при чём).
Отсчёт — с **01.09.2026 00:00 по Москве** (Турнир №0), поэтому номера уже положительные: например, **Турнир №8 —
25.09–27.09.2026**, №9 начинается 28.09 в 00:00. Итоги подводятся автоматически при первом обращении к серверу
после окончания. Участник — тот, кто поймал в турнире хотя бы одну рыбу.

**Награды — отдельно в каждой из 4 категорий.** В категории сравниваются участники, у которых в ней есть
результат (N — их число); место / N: до 25% — золото, до 50% — серебро, до 75% — бронза. Если в категории
участник один — ему золото. Все награды игрока приходят **одним письмом** «Итоги турнира №N» (место, число
участников, медаль и награда по каждой категории). L — уровень рыбака, «шаг» — опыт от начала уровня L до L+1
(ур. 1: 100, 2: 280, 3: 390, 4: 530, 5: 850, 6: 1150, 7: 1500, 8: 2100, 9 и 10: 3100; обновление 6: 11: 6200,
12: 7400, 13: 8800, 14 и 15: 10 400). Категория «Опыт» считает **«опыт заработанный»** (см. «Обновление 6» ниже):
он растёт и у игроков 10 уровня, чей опыт заморожен до прибытия в Город.

| Категория | Золото | Серебро | Бронза |
|---|---|---|---|
| Улов → приманки | Волшебная наживка × (3 + ⌈L/2⌉), Блесна × 10 | Блесна × (4 + ⌈L/2⌉), Выползок × 10 | Мотыль × 10 |
| … с 11 ур. ещё | Глубинный червь × 5 | Глубинный червь × 3 | Глубинный червь × 2 |
| Заработок → предметы | 3 вида × (4 + L) | 2 вида × (2 + ⌈L/2⌉) | 1 вид × (1 + ⌈L/4⌉) |
| Опыт → монеты | 300 + 200·L | 150 + 100·L | 50 + 30·L |
| Самая крупная → опыт | 30% шага | 15% шага | 6% шага (не меньше 50) |

Опыт округляется до целого (половина — вверх). Предметы за заработок выбираются из набора уровня (у каждого игрока
в каждом турнире свои, но всегда одни и те же при пересчёте): ур. 1–3 — доска, верёвка, клей, смола, перо;
4–6 — блёстки, грузило, клей, верёвка, поплавок из пера; 7–10 — блёстки, скользящий поплавок, плетёная леска,
клей, малая сеть; 11–15 — бревно, МПК, гвозди, тонкая и тяжёлая экспертные лески, поверхностный и глубинный
поплавки (сетей и снастей — не больше 2 шт.). Таблицу для любого уровня показывает админка («Турниры»). Опыт из
наград игрок 10 уровня до Города получает монетами 1 : 1 (Р10) — это делает игра.

## Защита

Все важные запросы подписаны секретным ключом игрока (HMAC-SHA1), проверяется время и повтор запроса; лимиты:
60 запросов игрока за 10 минут, 10 регистраций и 20 попыток кода восстановления в час с одного IP, 10 неудачных
входов в админку за 15 минут. Сервер проверяет правдоподобность (уровень ↔ опыт, счётчики не уменьшаются,
не больше 40 рыб и 60 000 монет в минуту, размеры рыб не больше максимума вида; видов и достижений — не больше, чем
в данных игры `lib/fish.php`, с запасом 10 и 15). Подозрительные данные не
принимаются, у игрока растёт счётчик «Подозр.», а в заметках появляется запись. Кнопка «Принять новые
счётчики» на странице игрока разрешает честный откат прогресса.

## Обновление сервера

Залейте новые файлы поверх старых (кроме `config.php` — его не трогать). Если в обновлении есть `install.php`,
откройте его с ключом ещё раз (данные сохраняются) и снова удалите.

**Обновление с сервера 1.0 на 1.1 (обновление игры 4b):** загрузите всё заново (новые `index.php`, `lib/settings.php`,
папка `download/`), удалите старый `index.html`, затем **обязательно** откройте `install.php?key=…` ещё раз: он
добавит таблицу настроек `settings` и перенумерует уже сохранённые турниры под новый отсчёт (с 01.09.2026;
номера сдвигаются на +9, уже выданные награды повторно не выдаются) — в отчёте будет строка «Турниры
перенумерованы». Затем удалите `install.php`. До этого игра получает версию по умолчанию (0.4, сборка 4). Резервные копии базы делает панель
хостинга («Резервные копии»). Ошибки сервера пишутся в `Fishing-game/logs/error_log.php` (из браузера не открывается).

**Обновление 6 — сервер 1.2** (Docs/UPDATE6_FOREST_CITY.md §9, §14, Р24). Выкладывается **раньше клиента 0.6** и
полностью совместим с клиентами 0.4–0.5. Перед выкладкой — резервная копия базы. Залейте все файлы (новый
`lib/schema.php`, `lib/fish.php`, `lib/validate.php`, `lib/season.php`, `api.php`, `install.php`, `index.php`, админка).
Таблица `players` получает 4 столбца **сама** при первом запросе к API или админке (номер схемы — `settings.schema_version`
= 2); открыть `install.php?key=…` тоже можно — в отчёте будет строка «Добавлены столбцы обновления 6». Что меняется:
* уровни до **15** (порог 11 — 13 100, 12 — 19 300, 13 — 26 700, 14 — 35 500, 15 — 45 900). Клиент 0.6 сообщает
  свою шкалу (`stats.max_level`); у клиентов без неё уровень проверяется по-старому (до 10 при любом опыте);
* **разовый срез опыта**: клиент 0.6 уменьшает опыт выше 10 000 до 10 000 (срезанное — «стаж»). Сервер один раз
  принимает уменьшение опыта (не ниже 10 000) без отметки «подозрительный», если в запросе `stats.xp_migration = 1`,
  и запоминает это (`players.xp_migrated`, на странице игрока — «срез принят»); повторное уменьшение — нарушение;
* **«опыт заработанный»** (`players.xp_earned`; при появлении столбца = опыту): сервер прибавляет прирост счётчика
  клиента `stats.xp_earned` с прошлого раза (`xp_earned_seen`), у старого клиента — прирост опыта. Турнир «Опыт»
  считается по нему, текущий турнир не сбивается. Прирост ограничен как опыт (3 000 в минуту + 5 000 + опыт из писем);
* **«стаж»** (`stats.xp_seniority` → `players.xp_seniority`, в профиле `seniority`): не больше, чем мог быть срезан;
* новые места (Лес, Город, Пещера), 10 обычных рыб, 17 экспертных рыб и 6 экспертных легенд (размеры — с запасом, до
  уточнения в данных игры), 36 новых предметов для писем (в админке — группа «Обновление 6»: игра 0.5 их не примет),
  лимиты видов и достижений считаются из `lib/fish.php`; страница скачивания показывает новое содержимое, только когда в
  «Версии игры» указана сборка 7 (0.6) или новее.

## Для разработчика: локальная проверка

PHP 8.2+ (`php`). Флаги:
`-n -d extension_dir=<папка PHP>/ext -d extension=pdo_sqlite -d extension=mbstring -d extension=openssl`.

* Тесты (запускают свой сервер на 127.0.0.1:8779 со свежей SQLite-базой `Server/local/test.sqlite`):
  `php <флаги> Server/tests/run_tests.php`.
* Ручной запуск: скопируйте `Server/local/config.example.php` в `Server/local/config.php` и задайте свои
  `install_key` и `admin_password`; затем `php <флаги> -S 127.0.0.1:8766 -t Server/Fishing-game` и
  `http://127.0.0.1:8766/install.php?key=<install_key>`, админка — пароль `admin_password`.
* Где сервер ищет настройки: 1) файл из переменной окружения `FV_CONFIG`; 2) `Fishing-game/config.php`
  (хостинг); 3) `Server/local/config.php` (локально). Отладочные `debug_time_offset` (сдвиг часов, для проверки
  турниров; локально — число секунд в `Server/local/time_offset.txt`), `ip_header` и `log_dir` действуют только
  для 1) и 3).
* `lib/fish.php` генерируется из `FVDatabase.cpp`: `php -n Server/tools/gen_fish.php` (генератор падает, если
  какого-то предмета из наград турнира — `FV_SEASON_REWARD_ITEMS` в `lib/season.php` — нет в данных игры).
  Обновление 6: места, рыбы, предметы и пороги 11–15 берутся из таблиц `U6_*` генератора, пока пакеты DATA не заполнят
  `FVDatabaseU6*.cpp`; то, что генератор разберёт там (форматы `AddLocation` / `AddFish` / `AddItem` / `AddBait`),
  главнее, а незнакомые ему id обновления 6 он печатает предупреждением — их надо дописать в `U6_*`.
* Протокол обновления 6 (сервер 1.2): `sync.stats` принимает ещё `max_level` (шкала уровней клиента: 10 или 15),
  `xp_earned` (счётчик «опыт заработанный»), `xp_seniority` («стаж»), `xp_migration` (1 — разовый срез опыта сделан);
  `profile` отдаёт ещё `xp_earned` и `seniority`. Старые клиенты эти поля не шлют и не читают.
* Протокол 4b: `ping` → `version {latest_build, latest_name, min_build, download_url, changelog}` (из таблицы
  `settings`, без неё — значения по умолчанию) и `server_version` ("1.1"; с обновления 6 — "1.2"). `sync.season.my` → для каждой категории
  (`fish`, `earned`, `xp`, `biggest`) `rank_*` (0 — нет места), `tier_*` (0 нет, 1 золото, 2 серебро, 3 бронза) и
  `n_*` (сколько участников с результатом в категории); `tier` / `best_pct` — лучшее из четырёх (для старых клиентов).
  Опыт за «Самую крупную»: `(шаг × процент + 50) div 100`, бронза — не меньше 50.
* Протокол — `Docs/UPDATE4_ONLINE.md` §3. Уточнения: `claimed` в письмах — число (0 = не получено, иначе
  unix-время); `nonce` должен быть новым в каждом запросе (повтор → `replay`); подпись можно передать и как
  `?sig=`; ошибки также `unknown_player` (нет такого pid — перерегистрация), `not_found`, `too_big`,
  `server_error`; в каждом ответе есть `server_time`; `sync` возвращает `rejected` (число отклонённых полей),
  `profile` — ещё и `biggest`; повторная регистрация с тем же `secret` возвращает того же игрока.
