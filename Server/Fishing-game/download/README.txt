Папка для установочного файла игры «Клёвая долина» (Android APK).
(Этот файл из браузера не открывается — он только для вас.)

Как выложить новую версию:
1. Панель хостинга -> «Менеджер файлов» -> <корень сайта>/Fishing-game/download/
2. Загрузите файл APK с именем KlevayaDolina.apk (старый файл замените).
   Ссылка для игроков: https://example.com/Fishing-game/download/KlevayaDolina.apk (подставьте свой домен)
3. Админка -> «Версия игры»: впишите название версии (например 0.5), номер сборки, «Что нового»
   и нажмите «Сохранить». Если старые версии больше не должны запускаться — поднимите «Минимальную сборку».
4. Проверьте страницу https://example.com/Fishing-game/ — там должна быть новая версия и размер файла.

Если файл называется иначе, укажите его ссылку в админке («Ссылка на APK»).
Файлы .htaccess, index.html и README.txt в этой папке не удаляйте.
